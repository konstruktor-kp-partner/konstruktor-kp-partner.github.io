# Конструктор письма партнёру

Одна HTML-страница без сборки и зависимостей: менеджер заполняет форму и получает письмо партнёру
(копирование в буфер, `.eml`), чек-лист запуска и HTML-лендинг с индивидуальными условиями.

- Адрес: https://konstruktor-kp-partner.github.io/
- Файл: `index.html`. Чтобы обновить опубликованную версию, достаточно заменить его и запушить в `main`.
- Данные формы никуда не отправляются: черновик хранится только в браузере (`localStorage`).
- Страница закрыта от индексации (`noindex`), но доступна любому, у кого есть ссылка.
